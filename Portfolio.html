Medical Laboratory Management System

A desktop administrative application designed for diagnostic clinics and pathology laboratories to centralize patient intake, sample logging, billing workflows, and test result reporting.

Core Application Windows & Modules

  • Patient Registration & Intake Window: Records demographic data, assigns unique patient IDs, logs referring physicians, and initializes active visits.
  • Test Request & Billing Interface: Selects individual tests or bundled panels, auto-calculates totals, applies discounts, processes payments, and generates printable tax invoices/receipts.
  • Sample Tracking & Result Entry Matrix: Form view for lab technicians to input numerical values or textual findings against reference ranges, with visual indicators for out-of-bounds metrics.
  • Report Generation Window: Preview and print engine outputting finalized diagnostic reports with automated electronic sign-offs and customized letterheads.

Key Technical Features

  • Automated calculation of total invoices and remaining balances.
  • Reference-range verification engine triggering visual alerts for critical test values.
  • Relational database backend maintaining historical patient logs and past visits.
  • Role-based access separating administrative billing from diagnostic result entry.

University Library Book Loan Portal

A web-based portal developed to digitize catalog exploration, automate student borrowing schedules, and streamline overall library administration.

Core Interface Views & Modules

  • Student Discovery & Catalog View: Searchable catalog interface equipped with filter controls for genre, author, ISBN, and real-time shelf availability.
  • Loan Checkout & Return Desk: Administrative module to scan or select book IDs, map them to student IDs, set dynamic return deadlines, and process check-ins.
  • User Portal & Borrowing History: Personalized view for registered students displaying currently checked-out titles, due-date countdowns, and historical reading logs.
  • Inventory Control Dashboard: Metrics panel displaying active loan counts, high-demand titles, lost inventory flags, and accumulated fine tracking.

Key Technical Features

  • Asynchronous search filtering without full page reloads.
  • Dynamic fine calculation algorithm operating on overdue date deltas.
  • State-driven catalog badges (Available, On Loan, Reserved).
  • Secure session management distinguishing student accounts from library administrators.

Medical Test Pricing Calculator

A targeted web utility built to simplify financial estimates for customizable diagnostic panels and multi-test packages.

Core Interface Modules

  • Interactive Panel Builder: Multi-select checklist interface organizing laboratory tests by category (e.g., Hematology, Biochemistry, Endocrinology).
  • Dynamic Cost Breakdown Sidebar: Real-time updating receipt panel reflecting itemized pricing, sub-totals, and calculated package adjustments as items are toggled.
  • Export & Print Modal: Form view to generate itemized cost estimates as formatted PDFs for patients prior to procedure authorization.

Key Technical Features

  • Real-time calculation engine reacting immediately to state changes without server roundtrips.
  • Package discount logic applying percentage adjustments when bundling prerequisite tests.
  • Export engine producing clean, client-facing PDF price quotes.
